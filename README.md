# Meu Dinheiro — Controle Financeiro para Estudantes

Sistema web em PHP + MySQL (PDO) + Bootstrap 5 + JavaScript.

## Como rodar (XAMPP)
1. Coloque esta pasta em `htdocs` e inicie Apache e MySQL.
2. Abra `http://localhost/MeusGastos/`: no primeiro acesso a **tela de instalação** pede os dados do MySQL e cria o banco sozinha.
3. Crie sua conta e use.
